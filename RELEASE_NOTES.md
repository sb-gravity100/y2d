# y2d 0.1.2

Fixes blocked CUTV and app-update links by explicitly allowing their GitHub URLs.

- Compact custom Windows setup matching the app, with installation location and shortcut options.
- Bundled FFmpeg, ffprobe and yt-dlp. No separate CLI installation or PATH setup.
- Hidden Windows downloader and version-probe processes.
- Manual app update checks in Settings, with a link to the latest stable release.
- Small CUTV companion promotion.

Download `y2d_0.1.2_x64-setup.exe` and run it. Close y2d before upgrading. Setup requires Microsoft Edge WebView2 Runtime. The installer is unsigned; Windows may display SmartScreen. Queue and history are still in memory. Automatic signed app updates are not enabled.
